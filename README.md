# English Tutor Bot  
**Telegram-бот — личный репетитор по английскому языку**

Бот помогает практиковать разговорный английский:  
- Принимает **голосовые сообщения**  
- Распознаёт речь (Speech-to-Text)  
- Исправляет грамматические, лексические и произносительные ошибки  
- Отвечает **голосом** + пишет текст + даёт перевод на русский  
- По запросу присылает **5 новых слов** по теме диалога с переводом и примерами  
- Ведёт историю диалога и прогресс пользователя  

---

### Возможности

- Голосовой ввод и голосовой ответ  
- Автоматическое исправление ошибок с пояснениями  
- Перевод на русский  
- Словарный запас: 5 новых слов по теме  
- Сохранение контекста диалога  
- Статистика ошибок и прогресса  
- Полностью контейнеризирован (Docker + Docker Compose)  

---

### Технологии

| Компонент          | Технология                         |
|--------------------|------------------------------------|
| Бот                | Python 3.11, `python-telegram-bot` |
| База данных        | **PostgreSQL 17**                  |
| Кэш / состояние    | **Redis 7.4**                      |
| Админка БД         | **pgAdmin 4**                      |
| Речь → Текст       | Whisper (локально)                 |
| Текст → Речь       | gTTS                               |
| Исправление ошибок | LLM через API (Chipp)              |
| Контейнеризация    | **Docker + Docker Compose**        |
| Деплой             | Selectel                           |
